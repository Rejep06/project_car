# Admin Frontend

Отдельная административная панель Automotive Platform на React, TypeScript и Vite.

## Возможности

- обзор пользователей, программ, заявок, обращений и операций;
- создание и редактирование программ уровней Старт, Стандарт и Премиум;
- управление несколькими адресами пополнения;
- хранение адресов разных сетей;
- настройка автоматической проверки USDT ERC-20 через Infura;
- включение, отключение и сортировка адресов;
- просмотр пользователей, балансов и реферальных связей;
- обработка нераспознанных блокчейн-переводов и выводов;
- создание, публикация и архивирование материалов компании;
- автоматическое формирование адреса публикации без ручного slug;
- поддержка пользователей;
- журнал административных действий;
- сохранение авторизации после обновления страницы.

## Запуск

```bash
cp .env.example .env
npm ci
npm run dev
```

Переменная окружения:

```env
VITE_API_BASE_URL=http://localhost:8000/api/v1
```

Production-проверка:

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

## Программы

Форма программы не содержит старых полей `slug` и `game/application`. Администратор выбирает один из уровней:

```text
starter  → Старт
standard → Стандарт
premium  → Премиум
```

## Адреса пополнения

Раздел **«Адреса пополнения»** позволяет:

- добавлять несколько кошельков;
- указывать сеть каждого адреса; текущий принимаемый актив — USDT;
- настраивать Infura, chain ID, контракт токена и подтверждения;
- отключать автоматическую проверку для произвольной сети;
- менять порядок отображения;
- отключать адрес для новых заявок без удаления истории.

Текущая автоматическая конфигурация:

```text
Ethereum Mainnet
USDT ERC-20
Infura
0xdac17f958d2ee523a2206206994597c13d831ec7
```
