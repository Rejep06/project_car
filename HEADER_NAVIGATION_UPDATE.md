# Обновление верхнего меню

В клиентском frontend переработана публичная шапка сайта.

## Что изменено

- Пункты меню больше не переносятся на две строки: для каждого пункта задано `white-space: nowrap`.
- «О компании» всегда отображается одной строкой.
- Навигация оформлена как компактная светлая панель с отдельным активным пунктом.
- Кнопки входа, регистрации, баланса, личного кабинета и выхода получили единый компактный стиль и иконки.
- Для широкого desktop-контейнера шапки используется отдельная максимальная ширина 1320 px.
- При ширине до 1260 px перегруженная desktop-навигация заменяется кнопкой меню, поэтому элементы не сталкиваются и не сжимаются.
- Планшетное меню открывается аккуратной панелью в две колонки.
- На телефоне меню автоматически перестраивается в одну колонку.
- В мобильную навигацию добавлены понятные иконки и визуальное выделение текущего раздела.
- Меню закрывается после перехода, по клавише Escape и при возврате к широкому экрану.

## Файлы

```text
customer-frontend/src/components/PublicLayout.tsx
customer-frontend/src/styles/pages.css
customer-frontend/src/styles/responsive.css
```

После установки изменений необходимо пересобрать клиентский frontend:

```bash
docker compose build --no-cache customer-frontend
docker compose up -d --force-recreate customer-frontend
```
